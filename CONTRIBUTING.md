Hello!

We are open to any contributions for Alnix!

Everything contributed, including code, wallpapers, other assets, etc. are going to be licensed under GPL 3.0 license, available in the LICENSE file in the root of this repo.

If you want to contribute any software to the Alnix repository, please open an Github issue, or contact the appropriate developers/team using the methods below.

AI contributions are not allowed, according to the policy in AI.md in the root of the repo.

To build Alnix locally for testing:
1. Use an Arch-based Linux distribution, or have access to Arch Linux related tools like pacman, archiso, etc.
2. Git clone this repo completely
3. Run build-iso.sh as root, using sudo or other tools
4. This will take a long time
5. After it finishes, it will print out the location of the compiled .iso

To contact the developers:
Email the appropriate one using the mails in https://alnix.org/devs
Join the Discord server, linked here, and go to the appropriate channel: https://alnix.org/contact
